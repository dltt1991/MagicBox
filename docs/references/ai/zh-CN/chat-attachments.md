# 聊天附件

## 目的

附件需要根据模型能力和文件大小，以合适形式进入模型上下文。系统优先使用模型原生支持的文件/图片 part；不支持或过大时，退化为提取文本和工具读取。

## 路由策略

- 支持图片的模型可以接收图片 part。
- 支持原生文件的模型可以接收文件 part。
- 文本类附件可以提取内容后进入上下文。
- 超过限制的内容通过 `read_file` 等工具分页读取。

## Agent session

Claude Code 智能体会话还会处理 assistant file attachments 和工作区文件。driver 会根据模型是否支持图片、是否支持附件读取来构造 SDK 用户消息。

## 原则

- 不把巨大文件一次性塞进 prompt。
- 保持 UI parts 和 model messages 的边界清晰。
- 溢出内容交给工具读取，让模型按需分页。

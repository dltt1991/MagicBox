# 知识库产品规格

> 中文副本，对应英文原文：[docs/references/knowledge/experiment/knowledge-product-spec.md](../knowledge-product-spec.md)。

说明知识库产品语义、用户场景和 Agent 管理知识库的目标。

## 要点

- 知识库是可被检索和管理的用户知识集合。
- Agent 可以在受控工具下读写知识。
- 产品体验要区分知识组织、搜索和引用。
